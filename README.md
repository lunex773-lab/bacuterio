# PHAGE: Inner World

1体のバクテリオファージから始まる感染・増殖の過程を、細胞レベルで自由に観察できる3Dシミュレーター（設計書 v1.0 の MVP 実装）。

- **ジャンル**: 観察特化型・生物学的シミュレーション
- **実装**: TypeScript + Three.js（Web 3D）。PC / iOS / Android のブラウザで動作
- **将来**: シミュレーションコアは描画非依存で書かれており、Unity 6 への移植を前提にしています → [docs/UNITY_MIGRATION.md](docs/UNITY_MIGRATION.md)

> バクテリオファージは細菌に感染するウイルスです。本作はヒト細胞への感染を扱わず、ヒト腸管の粘液層上にある細菌バイオフィルムを舞台に、細菌群集を介した増殖を描きます。

## 起動

```bash
npm install
npm run dev        # http://localhost:5173 （--host 付きなので同一LANのスマホからも開けます）
npm run build      # dist/ に静的ファイルを出力（任意の静的ホスティングで配信可）
npm test           # シミュレーションの自動テスト（描画なし）
```

## 遊び方

1. タイトル画面で観察するファージ（T4型 / T7型）と実験条件（乱数シード・初期細菌数・非適合種の割合・描画品質）を選ぶ
2. 「環境へ入る」→ 画面をクリック／タップしてファージを1体だけ放つ（自動配置も可）
3. 追跡中のファージをカメラが追従します。吸着 → DNA注入 → 宿主の乗っ取り → ゲノム複製 → 粒子の組み立て → 溶菌 と進み、子孫の1体に追跡が引き継がれます（系譜を記録）
4. 時間操作（一時停止・×1〜×180）、統計・グラフ・イベントログ、細菌やファージのクリックで詳細表示、断面表示、視点保存、セーブ／ロード

| 操作 | PC | スマートフォン |
|---|---|---|
| 回転 | 左ドラッグ | 1本指ドラッグ |
| 移動 | 右ドラッグ | 2本指ドラッグ |
| 拡大縮小 | ホイール | ピンチ |
| 選択 / 追従 | クリック / ダブルクリック | タップ / ダブルタップ |
| キー | Space 再生停止・1〜5 速度・F 追跡対象へ・C 断面・O 全体・L 言語 | 下部タブでパネル切替 |

## 見どころ（観察スケール）

| スケール | 表示 |
|---|---|
| 微生物群集 | コロニーの分布、感染の波、集団モデルのファージ密度雲 |
| 細菌 | 状態ごとの色＋形状（抵抗性=縞、休眠=くすみ、非適合種=球菌）、膜の揺らぎ、感染細胞の膨張と明滅、溶菌の破裂 |
| 細胞内部 | 近づくと半透明の細胞に切り替わり、リボソーム・宿主DNA・複製中のファージDNA・組み上がるビリオンが見える。追跡ファージは尾繊維が広がり尾鞘が収縮してDNAを注入 |

ファージは実寸（T4: 頭部約86×111 nm、尾部約100 nm）で描画し、遠景では蛍光標識した粒子のような光点で表します。

## アーキテクチャ（設計書 §2 対応）

```
src/
├── core/                 SimulationClock, SimulationWorld, SimulationConfig, EventQueue, Random
├── simulation/           描画非依存のシミュレーション（Unity移植対象）
│   ├── bacteria/         細菌の状態・成長・分裂・休眠・接触力学
│   ├── phage/            個体モデルのファージ（ブラウン運動・遭遇吸着・失活）
│   ├── infection/        溶菌サイクルの状態機械（細胞が保持）
│   ├── population/       集団モデル（ボクセル個数）と個体⇔集団の切替
│   ├── environment/      ボクセル環境（栄養・拡散・供給）
│   └── spatial/          空間ハッシュ
├── data/                 パラメータ（JSON, 根拠メタデータ付き）
├── visualization/        Three.js 描画（状態を読むだけで書き換えない）
├── observation/          HUD・グラフ・イベントログ・追跡
├── save/                 バージョン付きセーブ／ロード
├── i18n/                 日英切替
└── app/                  ゲーム進行・入力・フレームループ
tests/                    シミュレーションの自動テスト
```

設計上のルール（設計書 §2）: 3D オブジェクトは生物学的状態の正本ではありません。`SimulationWorld` が状態を持ち、`visualization/` はそれを参照するだけです。描画品質を落としても計算結果は変わりません。

### シミュレーションの要点

- **固定時間刻み**（0.25 s）。描画はフレームレートで補間。一時停止中は時間が進まず、高速再生時は1フレームの計算予算を超えると実効速度を落として表示（「処理上限」表示）
- **個体／集団ハイブリッド**: 追跡個体の周辺は個体として、遠方はボクセルごとの個数として計算。総数は両モードで一致（テストで検証）。追跡中の系譜の子孫は集団化しない
- **吸着**: 個体モードでは細胞周囲の遭遇殻内で `k / V_shell` のハザード、集団モードでは質量作用 `k·N·B/V`。どちらも同じ吸着速度定数 k に整合
- **感染の段階**: 吸着 → DNA注入 → 宿主乗っ取り → ゲノム複製（暗黒期）→ 粒子組み立て → 溶菌。細胞内の粒子数は段階と経過時間から導出
- **宿主の生理状態**: 栄養が乏しい細胞は成長が遅く、感染の進行が遅く、バーストが小さい。栄養が閾値を下回ると休眠
- **抵抗性**: 既存の受容体変異株（少数）と分裂時の変異。受容体を失った細胞には吸着しない
- **再現性**: 乱数は `xoshiro128**`。同じ設定・シード・操作ログで同じ計算経路を再現（`SimulationWorld.replay`）

### 科学的リアリティの管理（設計書 §3.5）

全パラメータが `evidenceLevel`（文献値の範囲／近似／仮定）、`modelType`（実測ベース／近似モデル／演出）、出典・説明、不確実性を持ち、ゲーム内の「モデル情報」から確認できます。観察のために意図的に誇張している値（耐性変異率・既存耐性株の割合・細菌密度）もそこに明記しています。

## テスト（設計書 §10）

`npm test` で以下を検証します: 初期状態（ファージ1体）、非適合種に感染しない、受容体欠損株に吸着しない、感染段階の遷移順、ファージ総数の保存則（個体＋集団）、モード切替での総数保存、溶菌イベントと集計の一致、一時停止中に時間が進まない、バックグラウンド復帰時の長フレームの扱い、セーブ前後の状態ハッシュ一致と継続計算の一致、同一シードでの再現・リプレイ、複数シードでのバーストサイズと潜伏期の統計的妥当性。
